# Medical_Appointment_Task1
# Task 1: Data Cleaning and Preprocessing

## Dataset
Medical Appointment No Shows Dataset

## Tool Used
Microsoft Excel

## Data Cleaning Steps Performed

1. Checked for missing values
2. Removed duplicate records
3. Renamed column headers
4. Standardized Gender values
   - F → Female
   - M → Male
5. Standardized No-show values
   - Yes → Missed
   - No → Showed
6. Verified date columns and formatting
7. Removed invalid age records (Age < 0)
8. Created cleaned dataset

- Medical_Appointment_Cleaning.xlsx
- cleaned_medical_appointments.csv

## Outcome

Prepared a clean dataset ready for analysis.
